# 14. 二维密度图 运行说明

## 图形类型
- **二维核密度热力图**

## 脚本位置
- `Code/14. 二维密度图.R`

## 运行前准备
```r
install.packages(c("ggplot2", "dplyr", "tidyr", "scales", "RColorBrewer", "lubridate", "treemapify", "ggalluvial"))
```
> 以上依赖为合集写法；实际运行本脚本时会按需调用，缺哪个安装哪个即可。

## 运行方式
```r
source("Code/14. 二维密度图.R")
```

## 输入与输出
- 输入：脚本内置模拟数据（无需额外数据文件）。
- 输出：当前工作目录下生成图片文件（PNG，320 dpi）。

## 可自定义项
- `plot_data`：替换为你自己的真实数据。
- 配色：修改 `scale_fill_*()` / `scale_color_*()`。
- 版式：修改 `theme()` 中字号、图例位置、坐标轴样式。
- 导出：修改 `ggsave()` 的尺寸、分辨率和格式。

## 常见问题
1. **报错“there is no package called xxx”**：先 `install.packages("xxx")` 安装缺失依赖。
2. **中文显示异常**：可在系统安装中文字体后配合 `showtext` 处理。
3. **输出文件找不到**：用 `getwd()` 查看当前工作目录，文件会导出到该目录。
