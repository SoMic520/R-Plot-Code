# 20. 环形图（出版级）运行说明

## 1) 脚本位置
- `Code/20. 环形图.R`
- 共享主题函数：`Code/00. 出版级绘图主题与导出函数.R`

## 2) 适用场景
- 论文主文图 / 补充材料图的初稿与定稿。
- 需要**统一版式**（字号、线宽、图例）和**投稿友好导出**（PDF + 600 dpi TIFF）。

## 3) 运行前依赖
```r
install.packages(c(
  "ggplot2", "dplyr", "tidyr", "scales", "RColorBrewer",
  "ggpubr", "viridis", "cairoDevice", "showtext",
  "treemapify", "ggalluvial"
))
```
> 注意：并非每个脚本都需要全部包；缺哪个装哪个即可。

## 4) 运行方式
```r
source("Code/20. 环形图.R")
```

## 5) 输出文件（默认）
- `donut_publication.pdf`（矢量格式，推荐投稿主文件）
- `donut_publication.tiff`（600 dpi，LZW 压缩，常见期刊要求）
- `donut_publication.png`（快速预览）

## 6) 出版级参数（建议）
- 尺寸：`180 mm × 140 mm`（可在 `save_pub()` 里改）
- 分辨率：`600 dpi`（TIFF）
- 字体：建议在本机安装英文/中文投稿字体后统一替换
- 颜色：优先色盲友好调色（Dark2 / Set2 / viridis）

## 7) 如何替换为真实数据
1. 保留 `p <- ggplot(...) + ...` 结构。
2. 仅替换 `plot_data` 构造区块为你的数据导入与整理。
3. 确认分组变量是 `factor` 且 level 顺序符合科研叙事。
4. 导出前检查坐标轴单位、显著性标注与图例标题是否完整。

## 8) 常见问题
- **包缺失**：先安装报错里提示的包。
- **中文乱码**：使用 `showtext` 并指定可用中文字体。
- **文件找不到**：`getwd()` 查看当前工作目录，输出默认在该目录。
